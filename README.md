# 🕵️‍♂️ Washington, DC Crime Analysis Dashboard

## 📌 Overview
This project presents a comprehensive analysis of crime patterns in Washington, DC using an interactive data visualization dashboard. The aim is to identify trends in crime methods, time of occurrence, locations, and district-level distribution to assist in understanding and improving public safety strategy.

## 📊 Dashboard Preview
![Washington Crime Dashboard](dashboard/Washington%20Crime_page-0001.jpg)

## 🔍 Key Features
- 📅 **Crime by Day & Time** – Spot peak crime hours and weekday trends
- 🔫 **Crime by Method** – Breakdown by gun, knife, and other means
- 📍 **Location Heatmap** – Crime density shown on a map
- 🕒 **Time to Resolution** – Measure efficiency in solving crimes
- 🏙 **District-Level Comparison** – Explore performance across 7 districts
- 🧩 **Property vs Violent Crime** – Separate views for different crime categories

## 🗂️ Dataset Information
- **Source**: *(Onyx Data -DataDNA Dataset Challenge - Washington Crimes Dataset - March 2025)*
- **Records Analyzed**: 3,867 crime reports


## 🧪 Tools & Technologies
- 📈 **Power BI** (for dashboard creation)
- 📊 **Excel / CSV** (for data cleaning)
- 🧮 Basic statistical aggregation


## 📈 Analysis Highlights
- **Evening crimes dominate** with 1,663 reported cases
- **Guns** were the most used weapon (1,523 incidents)
- **District 5** had the highest number of reported crimes (773)
- **District 7** recorded the fewest crimes (289)
- Most crimes were **property-related** (3,446 out of 3,867)
